# Adicted Website

Initial working concept for the Adicted performance marketing agency website.

## Direction
Dark editorial performance-marketing aesthetic using Adicted yellow, off-white and deep navy. The experience is built around experimentation rather than generic agency messaging.

## Structure
- Hero — Stop Spending. Start Learning.
- Advertising channel marquee
- Problem / positioning
- Media Buying, Creative Testing, Funnel Strategy, Growth Experiments
- Test → Learn → Scale methodology
- Selected results placeholders
- Contact CTA

## Run locally
No build step is required for this first prototype. Open `index.html` directly or serve the directory with any static server.

## Note
The case-study metrics in this initial concept are illustrative placeholders and must be replaced with verified Adicted/client results before production launch.
